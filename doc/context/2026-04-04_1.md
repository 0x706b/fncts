## Documentation Pattern Used

All JSDoc comments follow this format:
- The file uses `@tsplus` annotations for TypeScript+ tooling
- Functions already documented were left unchanged (e.g., `absorbWith`, `asJust`, `bimap`, `catchAll`, etc.)
- The `IO<R, E, A>` type represents an effectful computation with environment `R`, error `E`, and success `A`
- Total functions documented: **100+ in api.ts** + **80+ across api/ directory**
