# Agent Instructions

This is the fncts repository. fncts is a TypeScript project encompassing

- Functional programming patterns
- Data structures
- Effect systems
- Concurrency
- Utilities

It includes "original" code, hard forks, and ports of other works.

## Development

Load skills from `./.agents/skills` when needed.

- The git base branch is `trunk`
- Use `pnpm` as the package manager

### Principles
- **Reliability, clarity, readability**: Favor clear and maintainable solutions
- **No uncecessary comments**: Avoid inline comments unless absolutely required to explain unusual or complex logic.
  Comments in jsdocs are acceptable.

### Validation Steps
After making changes, always run the following steps in order:
- Type checking/build: `pnpm build`
- Tests, using `--filter` to run only affected packages when applicable: `pnpm [--filter @fncts/base] test run`

## Code Style

**Always** look at existing code in the project to learn and follow established patterns before writing new code.

Do not worry about getting code formatting perfect while writing. The format and lint steps will automatically
format code according to this project's style guidelines.

### Barrel Files

This project does _not_ use `index.ts` files _ever_. Always use an adjacent file with the name of the directory as the
barrel file. Barrel files are automatically generated by `eslint --fix` with a comment:

```ts
// Assuming this file is List.ts and there is an adjacent directory List

// codegen:start { preset: barrel, include: ./List/*.ts }
```

If more information is necessary to write the codegen comment, the source of the codegen plugin is located in
`./packages/codegen`.
